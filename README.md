# Академика Study — история, 5 класс

Готовый мини‑сайт с интерактивными заданиями по первым трём параграфам учебника В. Р. Мединского и А. О. Чубарьяна «История Древнего мира. 5 класс» (2025):

1. § 1 «Древнейшие люди»
2. § 2 «Первобытные охотники и собиратели»
3. § 3 «Верования и искусство»

## Что уже работает

- главная страница → курс → тема → задания;
- один / несколько вариантов ответа;
- сортировка карточек;
- пары;
- расстановка по порядку;
- ввод ответа;
- поле для рисования;
- подсказки и объяснения;
- звёзды и результат по теме;
- отдельный режим учителя;
- добавление, изменение, удаление и перестановка заданий;
- добавление собственных тем;
- персональные ссылки учеников;
- сохранение результатов учеников в общей базе;
- резервная копия курса в JSON.

## Как посмотреть прямо на компьютере

Можно просто открыть `index.html`. Это демо‑режим: задания работают, но изменения и прогресс сохраняются только в этом браузере.

## Как запустить полноценную версию

Нужен Python 3.10+ — дополнительных библиотек нет.

```bash
python server.py
```

После запуска открыть:

`http://127.0.0.1:8000`

Учительский PIN по умолчанию: `2468`.

Для публичного сайта обязательно используйте HTTPS и задайте свой PIN переменной окружения:

```bash
TEACHER_PIN=ваш_сложный_pin python server.py
```

На Windows PowerShell:

```powershell
$env:TEACHER_PIN="ваш_сложный_pin"
python server.py
```

## Как ребёнок получает отдельный доступ

1. Открыть «Режим учителя».
2. Перейти во вкладку «Ученики и ссылки».
3. Нажать «Добавить ученика».
4. Скопировать созданную персональную ссылку и отправить ребёнку.

Ребёнку не нужен аккаунт учителя или ChatGPT.

## Где хранятся данные

При запуске через `server.py` рядом с сайтом автоматически создаётся база `akademika.sqlite3`. В ней хранятся ученики, результаты и отредактированный курс.

## Публикация на домене

Проект можно разместить на обычном Python‑хостинге/VPS и привязать домен вроде `learn.akademikakhv.ru` или `akademika-study.ru`. Для постоянного сохранения результатов серверу нужен постоянный диск, чтобы файл `akademika.sqlite3` не удалялся при перезапуске.

## Источники содержания

Формулировки заданий написаны заново, а содержание сверено с учебником и открытыми материалами к параграфам. Проект не содержит сканированных страниц учебника.


## Railway / облачный хостинг

Для постоянного хранения SQLite подключите persistent volume и задайте переменную окружения:

```
DATA_DIR=/data
```

Точку монтирования диска/volume задайте `/data`. Учительский PIN задайте отдельной переменной `TEACHER_PIN`.
Проект уже содержит `Dockerfile` и читает порт из переменной `PORT`, поэтому подходит для Docker-хостинга.
